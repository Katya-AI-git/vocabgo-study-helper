Vocabgo Study Helper（社区二次开发版）
=====================================

这是一个基于公开 MIT 开源项目修改的本地词汇学习辅助工具。
本项目与其修改者不是 VocabularyGO、微信或任何学校的官方项目。

主要功能
--------

- 班级任务、学习任务和自学任务的本地辅助练习。
- 本地题库与题目内容复用。
- 本地词表、教材和电子书导入。
- TXT、CSV、JSON、DOCX、EPUB 和文字型 PDF 解析。
- 本地资料优先匹配；无法确定时再调用用户自行配置的模型接口。
- 自适应思考模式，降低简单题的推理 token 开销。
- 填空题会优先使用当前任务的词表约束模型答案，减少同义词和词形不一致。
- 任务词表按原形提供，支持复数、时态等正确词形变化。
- 组词题支持 `sb.`、`sb.'s`、`times'`、`sth.`、`somebody` 等占位词归一，并修正短语兜底顺序。
- 服务端 `answer_result=2` 暂不当作成功，继续按未通过处理，避免错词无法重刷。
- 班级学习任务由“班级学习轮数”控制，测试任务保留最多 6 个内部会话。
- “允许重刷已完成学习任务”的勾选状态会保存，用于重刷进度已满但仍有未满分词的学习任务。
- 服务端返回正确答案时，会兼容空格和逗号两种短语格式。
- 测试任务保留全部词，允许超分互补以补足任务总分。
- 启动时可后台检查 GitHub 新版本，支持前往更新或忽略该版本。
- 设置页提供“检查更新”按钮，可随时手动检测。
- 本地资料库支持图片 OCR 导入，优先使用本地 Tesseract，本地不可用时再使用视觉模型。
- 批量导入超过 20 张图片且需使用视觉模型时，会先提醒 token 消耗。
- Windows 图形界面、命令行和 EXE 打包脚本。

任务类型
--------

- task_type=1：学习任务，可以使用“班级学习轮数”重复学习。
- task_type=2：测试任务，只有一次机会，程序固定只执行一次。
- 默认只处理进度未满的任务。
- 需要重刷进度 100% 的学习任务时，勾选“允许重刷已完成学习任务”。
- 服务端返回“存在小节任务未完成”时，程序会自动重新提交一次选词后继续；
  该操作不会清空已提交成绩。

仓库不包含
----------

- 不包含用户令牌、微信账号或个人信息。
- 不包含 API Key。
- 不包含 bank.json 或 materials.json。
- 不包含用户导入的教材、词表或题库。
- 不包含 .venv、dist、build 和个人运行日志。

运行方式
--------

源码运行：

1. 安装 Python 3.10 或更高版本。
2. 在项目目录执行：

   pip install -r requirements.txt
   python vocabgo_app.py

带自动 Python 安装的 Windows 入口：

   双击 启动.bat

使用说明：

   双击 open_manual.bat

然后通过浏览器查看 manual.html。

数据位置
--------

题库、词典缓存和用户资料默认保存在：

%LOCALAPPDATA%\VocabgoAuto

本仓库不携带任何个人数据。
