Vocabgo Study Helper（社区二次开发版）
=====================================

这是一个基于公开 MIT 开源项目修改的本地词汇学习辅助工具。
本项目与其修改者不是 VocabularyGO、微信或任何学校的官方项目。

主要功能
--------

- 班级任务、学习任务和自学任务的本地辅助练习。
- 本地题库与题目内容复用。
- 本地词表、教材和电子书导入。
- TXT、CSV、JSON、DOCX、EPUB 和文字型 PDF 解析。
- 作答默认走用户自行配置的模型接口；本地资料与词典作为提示和兜底。
- 答案不稳时自动升级为思考模式重试，推理额度给足（最高 16384 tokens）。
- 每题独立询问模型多次取多数：班级任务与自学任务都是 3 次。
- 上下文不做截断式节省：任务词表全量、已知释义 200 条、资料片段最多 12000 字。
- 填空题会优先使用当前任务的词表约束模型答案，减少同义词和词形不一致。
- 任务词表按原形提供，支持复数、时态等正确词形变化。
- 组词题支持 `sb.`、`sb.'s`、`times'`、`sth.`、`somebody` 等占位词归一，并修正短语兜底顺序。
- 服务端 `answer_result=2` 暂不当作成功，继续按未通过处理，避免错词无法重刷。
- 任务体检（🩺）：开刷前看进度、得分、累计用时与词分分布，两次对比判断任务是否已被服务端固定。
- 启动脚本与 ZIP 下载路径已修好：`.bat` 换行写死 CRLF，`prepare.bat` 建环境前先验证 tkinter。
- “允许重刷已完成学习任务”的勾选状态会保存，用于重刷进度已满但仍有未满分词的学习任务。
- 服务端返回正确答案时，会兼容空格和逗号两种短语格式。
- 测试任务保留全部词，允许超分互补以补足任务总分。
- 启动时可后台检查 GitHub 新版本，支持前往更新或忽略该版本。
- 设置页提供“检查更新”按钮，可随时手动检测。
- 本地资料库支持图片 OCR 导入，优先使用本地 Tesseract，本地不可用时再使用视觉模型。
- 批量导入超过 20 张图片且需使用视觉模型时，会先提醒 token 消耗。
- Windows 图形界面、命令行和 EXE 打包脚本。

任务类型
--------

- task_type=1：学习任务，可以使用“班级学习轮数”重复学习。
- task_type=2：测试任务，只有一次机会，程序固定只执行一次。
- 默认只处理进度未满的任务。
- 需要重刷进度 100% 的学习任务时，勾选“允许重刷已完成学习任务”。
- 服务端返回“存在小节任务未完成”时，程序会自动重新提交一次选词后继续；
  该操作不会清空已提交成绩。

V1.0.7 修订说明
---------------

**作答更准：做题统一交给大模型判断**

这一版把「做题」统一交给模型：题库里答过的题、规则能唯一确定的题照旧秒答，
其余题目一律先问模型，本地资料和词典退到「提示 + 兜底」的位置。
没见过的新题型、口语化短语、词形变化，模型都能按题意作答，不会被规则挡在门外。

**作答额度给足，不再为省 token 牺牲准确率**

- 单次作答额度 512 → 4096 tokens；推理被截断时自动抬升，最高 16384。
- 选择题、填空题、组词题额度同步提高，长句与长短语不再被截断。
- 上下文不再压缩：任务词表全量送入（原先只给前 200 条），
  已知单词释义 40 → 200 条，本地资料片段 2400 → 12000 字，填空候选 2000 → 8000 字。
- 自学任务也改成每题独立询问 3 次取多数（原先 1 次）。

**启动与体检（延续 V1.0.6 的修复）**

- `.gitattributes` 把 `.bat` 换行写死为 CRLF：从 GitHub「Download ZIP」下载的包，
  双击 启动.bat 不再乱码闪退；`git clone` 与 Release 附件同样正常。
- `prepare.bat` 建环境前先验证 tkinter，缺 tcl/tk 会给出可执行指引。
- 任务体检（🩺）继续保留：开刷前看真实状态，两次对比判断是否已被服务端固定。

验证情况：

- 自动化测试 240 项通过。
- 4 项可选 OCR 测试因本机未安装 Tesseract 而跳过。
- 模型前置后的调用顺序有专门用例锁定（模型先答、资料兜底、规则不抢答）。

运行方式
--------

源码运行：

1. 安装 Python 3.10 或更高版本。
2. 在项目目录执行：

   pip install -r requirements.txt
   python vocabgo_app.py

带自动 Python 安装的 Windows 入口：

   双击 启动.bat

使用说明：

   双击 open_manual.bat

然后通过浏览器查看 manual.html。

数据位置
--------

题库、词典缓存和用户资料默认保存在：

%LOCALAPPDATA%\VocabgoAuto

本仓库不携带任何个人数据。
