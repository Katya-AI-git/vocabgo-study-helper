Vocabgo Study Helper（社区二次开发版）
=====================================

这是一个基于公开 MIT 开源项目修改的本地词汇学习辅助工具。
本项目与其修改者不是 VocabularyGO、微信或任何学校的官方项目。

主要功能
--------

- 班级任务、学习任务和自学任务的本地辅助练习。
- 本地题库与题目内容复用。
- 本地词表、教材和电子书导入。
- TXT、CSV、JSON、DOCX、EPUB 和文字型 PDF 解析。
- 本地资料优先匹配；无法确定时再调用用户自行配置的模型接口。
- 自适应思考模式，降低简单题的推理 token 开销。
- 填空题会优先使用当前任务的词表约束模型答案，减少同义词和词形不一致。
- 任务词表按原形提供，支持复数、时态等正确词形变化。
- 组词题支持 `sb.`、`sb.'s`、`times'`、`sth.`、`somebody` 等占位词归一，并修正短语兜底顺序。
- 服务端 `answer_result=2` 暂不当作成功，继续按未通过处理，避免错词无法重刷。
- 班级学习任务由“班级学习轮数”控制；测试任务的内部会话随进度动态放宽，
  只要服务端还在往下出题就一直答到 100%（硬上限 40 个会话）。
- 测试任务中途不中断：单题出错先重试，仍不行就重新向服务端要当前进度接着答。
- 服务端灰度轮换 jv 混淆方案时，未登记的方案会做抢救式解码，不再当作“任务已结束”。
- 网络瞬时故障自动重试 3 次；业务错误码（如令牌失效）不重试，直接提示。
- 结构性题型（补全单词、多空首字母、补全句子、看义选词）由规则直接算出答案，
  不消耗大模型调用。
- “允许重刷已完成学习任务”的勾选状态会保存，用于重刷进度已满但仍有未满分词的学习任务。
- 服务端返回正确答案时，会兼容空格和逗号两种短语格式。
- 测试任务保留全部词，允许超分互补以补足任务总分。
- 启动时可后台检查 GitHub 新版本，支持前往更新或忽略该版本。
- 设置页提供“检查更新”按钮，可随时手动检测。
- 本地资料库支持图片 OCR 导入，优先使用本地 Tesseract，本地不可用时再使用视觉模型。
- 批量导入超过 20 张图片且需使用视觉模型时，会先提醒 token 消耗。
- Windows 图形界面、命令行和 EXE 打包脚本。

任务类型
--------

- task_type=1：学习任务，可以使用“班级学习轮数”重复学习。
- task_type=2：测试任务，只有一次机会，程序固定只执行一次。
- 默认只处理进度未满的任务。
- 需要重刷进度 100% 的学习任务时，勾选“允许重刷已完成学习任务”。
- 服务端返回“存在小节任务未完成”时，程序会自动重新提交一次选词后继续；
  该操作不会清空已提交成绩。

V1.0.5 修订说明
---------------

本次版本解决的核心问题是：**测试任务刷到一半中断**。
测试任务只有一次机会，中途停下等于这一次机会白白浪费。查证后发现是三处独立缺陷，
任意一处都足以单独造成中断：

1. 响应解码失败被当成“任务结束”。服务端会灰度轮换 jv 混淆方案，
   没登记过的方案原先会把原始 base64 字符串塞回 data 字段，上层取不到题目，
   就把这一轮判定为服务端没有后续题目。现在增加了抢救式解码
   （偏移截断尝试、按已知规则的删除位反向补齐），
   确实解不开时抛出可重试的解码异常，由请求层重试，不再污染正常答题流程。

2. 网络抖动导致整场退出。请求层原先一次失败就直接抛出异常，
   异常冒泡到答题循环后直接返回。现在网络类异常自动重试 3 次
   （0.8 秒递增退避）；业务错误码（例如 11003 需要安全验证）不重试，原样上报给用户。

3. 内部会话数量固定为 6 个。测试任务答不完也会收工。
   更严重的是读取任务进度失败时，进度会被回落成 0，
   从而误触发“本次会话没有进展”的判断，造成第二次提前停止。
   现在只要进度仍在增长就动态放宽会话上限（硬上限 40），
   读取进度失败时沿用上一次的值。

同时在题型处理上新增了结构性题型引擎 `vocabgo/templates.py`，
覆盖四类原先完全依赖大模型猜测、但实际上可以通过规则精确计算的题目：

- `mode 73` 多空首字母（题干形如 `{gr}{sto}`，答案需提交 JSON 数组）
- `mode 51~54` 补全单词（服务端提供的 `w_tip` 前缀与 `w_lens` 词长可直接定位答案）
- `mode 41~44` 补全句子（用中文备注与释义做重叠比对）
- `mode 17~18` 看义选词（题干为中文、选项为英文，反查释义表）

这些题目由规则直接算出答案，不产生大模型调用开销。
计算不出来时返回空值，交回大模型或试答案链路，不做无依据的猜测。

验证情况：

- 自动化测试 263 项通过（新增 30 项，分别覆盖中断韧性与题型引擎）。
- 4 项可选 OCR 测试因本机未安装 Tesseract 而跳过。
- 程序自检关键项通过。

更详细的中断原因分析与逐步排查方法见 `docs/测试任务中断排查与修复.txt`。

仓库不包含
----------

- 不包含用户令牌、微信账号或个人信息。

运行方式
--------

源码运行：

1. 安装 Python 3.10 或更高版本。
2. 在项目目录执行：

   pip install -r requirements.txt
   python vocabgo_app.py

带自动 Python 安装的 Windows 入口：

   双击 启动.bat

使用说明：

   双击 open_manual.bat

然后通过浏览器查看 manual.html。

数据位置
--------

题库、词典缓存和用户资料默认保存在：

%LOCALAPPDATA%\VocabgoAuto

本仓库不携带任何个人数据。
