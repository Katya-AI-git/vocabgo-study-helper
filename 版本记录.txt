词达人工具优化版 版本记录
==========================

更新时间：2026-10-26


V4
--
发布日期：2026-10-26

填空题优化：

- 内部版本号统一为 `1.0.3`，与 GitHub 的 `V1.0.0 / v1.0.1 / v1.0.2` 发布序列保持一致。
- 新增 GitHub Release 更新检测：启动后后台检查新版本，可前往 GitHub 更新，也可选择忽略该版本。
- `mode=51` 把当前任务词表直接作为模型的答案候选范围，不依赖本地词库是否收录新词。
- 启动日志会显示“填空约束 v3”，失败样本也会记录 `prompt_version`，用于确认新代码是否已重新加载。
- 中文含义会先翻译成英文候选，再去掉题干里的固定部分，例如 `in batches` 会裁成 `batches`。
- 模型如果返回完整搭配，提交前会自动裁剪，只保留空格中的答案。
- `mode=32` 组词题支持 `sb.`、`sb.'s`、`times'`、`sth.`、`somebody` 等占位词归一，并修正兜底排序，避免把占位词放到错误位置。
- `mode=51` 提示词不再附带无关的 40 个旧单词释义，只保留当前题、中文含义和相关候选。
- 保持 `deepseek-flash` 和原来的三票投票，不额外增加每题的大模型调用次数。
- 填空题失败时写入 `failed_fill.jsonl`，记录题干、中文含义、候选、模型原始输出和服务端返回，便于离线复现。
- 服务端 `answer_result=2` 暂不当作成功，继续按未通过处理，避免错词被误判为完成而无法重刷。
- 班级学习任务由“班级学习轮数”控制，不再在单轮内部固定执行 6 个答题会话；测试任务仍保留最多 6 个内部会话以完成整套题。
- “允许重刷已完成学习任务”的勾选状态会持久保存，并在刷选中任务时明确记录是否生效；需要重刷 List 26 这类进度 100% 但仍有未满分词的任务时必须勾选。
- 单词语义按当前任务观察到的最高分自适应：最高 10 分就补低于 10 的词，最高超过 10 分则按实际最高分补词，避免固定阈值漏刷。
- 测试任务会保留全部词，允许部分词超过单词语义上限，从而用超分补足任务总分 100。
- 服务端返回 `answer_corrects` 时，会依次尝试原始空格格式和逗号格式，兼容 `orbit the sun` 与 `orbit,the,sun` 两种提交形式。

验证结果：

- 自动化测试：222 项通过。
- 可选 OCR 测试：4 项因本机没有 Tesseract 跳过。
- 在线小样本：3 道已知答案填空题，优化前 2/3 通过，优化后 3/3 通过。
- 在线复验：7 道实际被服务端拒绝的填空题，加入任务词表约束后 7/7 通过。
- 在线复验：`引用某人的话` 正确解析为 `quote,sb.`。
- 在线复验：`violate,sb.'s,privacy`、`for,old,times',sake`、`orbit,the,sun` 均正确解析。
- 示例提示词字符数从 696 降到 147。


V3
--
发布日期：2026-10-19

新增功能：

- 本地资料库：支持 TXT、MD、CSV、JSON、DOCX、EPUB 和文字型 PDF。
- 自动识别词表、短语和教材正文。
- 明确命中的题目由脚本直接作答，不调用大模型。
- 无法确定时只发送少量相关片段，不上传整本电子书。
- PDF 资料解析使用 pypdf。
- 自适应思考模式：基础题先关闭思考，答案不稳定时再开启思考重试。
- 句中专词义且没有本地证据时，直接使用思考模式。
- 分享版文档改为 manual.html，可通过 open_manual.bat 使用浏览器打开，不需要 Typora。
- 技术资料合并为 技术说明.txt。
- 新增本版本记录文件。

保留功能：

- 班级任务、学习任务和自学任务自动答题。
- 本地题库累积和按题目内容复用。
- 批量任务、自动续答和按阈值重练。
- 单实例保护，避免多个窗口同时写题库。
- 自动下载并校验官方 Python。
- 免安装 EXE。

验证结果：

- 自动化测试：202 项通过。
- 可选 OCR 测试：4 项因本机没有 Tesseract 跳过。
- EXE 自检：通过。
- PDF 解析组件：通过。
- 本地资料目录写入：通过。


V2
--
发布日期：2026-10-18

主要修复：

- 首次开始任务时可以重置选词。
- 服务器返回 20001 后自动续答时不再发送 reset_chose_words。
- 后续学习轮次不会反复回到 66%。
- 班级学习任务会读取 exist_little_task 状态。
- 修正班级任务类型映射：task_type=1 为学习任务，task_type=2 为测试任务。
- 服务端返回“存在小节任务未完成”时，学习任务和测试任务都会自动重置选词后重试一次。
- 自学任务采用相同的继续练习逻辑。

缓存优化：

- 系统提示固定，不再包含每次变化的 UUID。
- 采样编号移动到用户请求末尾。
- 保留三次投票和短语补采样。
- 增加缓存命中、未命中、推理和输出 token 统计。
