词达人工具快速使用说明
======================

一、应该双击哪个文件

1. 如果拿到的是 EXE 压缩包：
   先完整解压。
   双击 Vocabgo.exe。

2. 如果拿到的是源码自动安装包：
   先完整解压。
   双击 启动.bat。
   电脑没有 Python 时，程序会自动下载并安装官方 Python。

3. 不要直接在压缩包里双击程序。
   必须先把 ZIP 全部解压到一个普通文件夹。


二、第一次使用

1. 打开程序后，进入“设置”页。

2. 点击“一键填入推荐配置”。

3. 如果有 DeepSeek API Key，把密钥粘贴到“接口密钥”。
   不填写也能运行，但遇到资料库未覆盖的题目时，正确率可能下降。

4. 点击“保存设置”。

5. 进入“刷题”页，点击“登录获取令牌”。

6. 按界面提示用微信扫码授权。

7. 点击“刷新任务”。

8. 选中一个任务，点击“开始刷题”。


三、导入自己的词表或教材

1. 进入“设置”页。

2. 找到“本地资料库”。

3. 点击“导入资料”。

4. 选择 TXT、CSV、JSON、DOCX、EPUB 或文字型 PDF 文件。

5. 保持“刷题时优先使用本地资料”勾选。

程序会先查本地资料，明确找到答案时直接作答。
本地无法确定时，才调用大模型。


四、自适应思考

建议保持“按题型自动切换思考模式”勾选。

程序会对基础题使用低成本的关闭思考模式。
答案为空、格式异常或多票冲突时，再自动开启思考重试。


五、使用注意事项

1. 刷题期间不要在其他手机或电脑上登录同一个词达人账号。

2. 同一时间只运行一个刷题器。

3. 不要把自己电脑上的 config.json 发给别人。

4. 题库、词典缓存和用户资料保存在：
   %LOCALAPPDATA%\VocabgoAuto

5. 分享软件前，至少删除 config.json，避免泄露个人令牌和 API Key。


六、常见问题

问题：双击后提示病毒或“Windows 已保护你的电脑”。

处理：点击“更多信息”，再点“仍要运行”。


问题：提示用户令牌失效。

处理：重新点击“登录获取令牌”，使用自己的微信重新扫码。


问题：大模型调用失败。

处理：
1. 检查 API Key 是否正确。
2. 检查账号是否有余额。
3. 确认接口地址是 https://api.deepseek.com。
4. 点击“保存设置”，再点击“大模型体检”。


问题：导入 PDF 后没有识别到文字。

处理：该 PDF 可能是扫描图片版。
请先使用 OCR 软件转换为可搜索 PDF，或者改传 TXT、DOCX、EPUB。


问题：任务提示未开始。

处理：先在微信词达人中打开该任务，让它变成“进行中”，
然后回到程序重新“刷新任务”。
