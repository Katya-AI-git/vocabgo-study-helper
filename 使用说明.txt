======================

一、应该双击哪个文件

1. 如果拿到的是 EXE 压缩包：
   先完整解压。
   双击 Vocabgo.exe。

2. 如果拿到的是源码自动安装包：
   先完整解压。
   双击 启动.bat。
   电脑没有 Python 时，程序会自动下载并安装官方 Python。

3. 不要直接在压缩包里双击程序。
   必须先把 ZIP 全部解压到一个普通文件夹。


二、第一次使用

1. 打开程序后，进入“设置”页。

2. 点击“一键填入推荐配置”。

3. 如果有 DeepSeek API Key，把密钥粘贴到“接口密钥”。
   不填写也能运行，但遇到资料库未覆盖的题目时，正确率可能下降。

4. 点击“保存设置”。

5. 进入“刷题”页，点击“登录获取令牌”。

6. 按界面提示用微信扫码授权。

7. 点击“刷新任务”。

8. 选中一个任务，点击“开始刷题”。


三、导入自己的词表或教材

1. 进入“设置”页。

2. 找到“本地资料库”。

3. 点击“导入资料”。

4. 选择 TXT、CSV、JSON、DOCX、EPUB 或文字型 PDF 文件。

5. 保持“刷题时优先使用本地资料”勾选。

程序默认把题目交给大模型作答，本地资料和词典作为提示一起递过去。
大模型不可用、或者没给出稳定答案时，才由本地资料兜底直接作答。


四、自适应思考

建议保持“按题型自动切换思考模式”勾选。

程序先按关闭思考作答，速度最快；
答案为空、格式异常或多票冲突时，自动开启思考模式重试，推理额度给到够用为止。


五、使用注意事项

1. 刷题期间不要在其他手机或电脑上登录同一个词达人账号。

2. 同一时间只运行一个刷题器。

3. 不要把自己电脑上的 config.json 发给别人。

4. 题库、词典缓存和用户资料保存在：
   %LOCALAPPDATA%\VocabgoAuto

5. 分享软件前，至少删除 config.json，避免泄露个人令牌和 API Key。


六、常见问题

问题：列表里的“测试任务”和“学习任务”是什么意思？

处理：
1. 学习任务对应 task_type=1，可以按“班级学习轮数”重复学习。
2. 测试任务对应 task_type=2，只有一次机会，程序固定只执行一次。
3. 默认只处理进度未满的任务。
4. 需要重刷进度 100% 的学习任务时，勾选“允许重刷已完成学习任务”。


问题：提示“存在小节任务未完成”。

处理：
程序会先按正常方式继续；如果服务器明确返回这个错误，
会自动重新提交一次选词并继续答题。该操作不会清空已提交成绩。


问题：双击后提示病毒或“Windows 已保护你的电脑”。

处理：点击“更多信息”，再点“仍要运行”。


问题：提示用户令牌失效。

处理：重新点击“登录获取令牌”，使用自己的微信重新扫码。


问题：大模型调用失败。

处理：
1. 检查 API Key 是否正确。
2. 检查账号是否有余额。
3. 确认接口地址是 https://api.deepseek.com。
4. 点击“保存设置”，再点击“大模型体检”。


问题：怎么判断这条任务还能不能刷？

处理：
1. 在任务列表里选中一条任务，点“🩺 任务体检”。
2. 会读出进度、得分、累计用时和单词分数分布。
3. 隔几分钟再体检一次：进度和累计用时完全没变，说明这条任务已经停在断点处，
   换一条新任务更省时间。


问题：导入 PDF 后没有识别到文字。

处理：该 PDF 可能是扫描图片版。
请先使用 OCR 软件转换为可搜索 PDF，或者改传 TXT、DOCX、EPUB。


问题：任务提示未开始。

处理：先在微信词达人中打开该任务，让它变成“进行中”，
然后回到程序重新“刷新任务”。


七、升级到新版（直接覆盖，不用重配）

发布包是扁平结构（和 1.0.0~1.0.6 一致），所以**不用删旧的、也不用重新登录**：

1. 先关掉正在运行的程序（窗口右上角关闭，别留后台）。
2. 打开新 zip，把里面的文件**全选**，拖进你原来的程序文件夹。
3. 提示同名文件时选“替换目标中的文件”（等同“全部覆盖”）。
4. 双击 Vocabgo.exe（源码版双击 启动.bat）即可，版本号看“版本记录.txt”。

覆盖不会动你的数据：

- config.json（API Key、令牌设置）、bank.json（题库）、materials（导入的教材）
  都不在 zip 里，解压不会删除它们。
- 想彻底干净重来，才需要删掉整个文件夹（那样配置和题库会一起没）。

注意两点：

- 程序必须先退出再解压，否则 exe 和 _internal 里的文件被占用，会提示“无法替换”。
- 别把新 zip 解压到另一个新文件夹里当第二份用 —— 两份会各写各的题库，
  账号同时登录还容易触发风控。
- 源码版覆盖后如果目录里还留着 `vocabgo	emplates.py`，那是旧版遗留文件，
  删不删都不影响运行（新代码不引用它）。
