快速上手

本版本在 V2 基础上新增：

1. 本地资料库 2. 自适应思考模式 3. 文字型 PDF、DOCX、EPUB 教材导入 4. 用 pypdf 解析 PDF

本地资料库：

  • 在“设置”页点击“导入资料”。
  • 支持 TXT、MD、CSV、JSON、DOCX、EPUB 和文字型 PDF。
  • 脚本先在本地查询词表和教材，不消耗大模型 token。
  • 明确命中的选择题、短语题直接作答。
  • 无法确定时才把当前题目和少量相关片段交给模型。
  • 资料保存在 %LOCALAPPDATA%\VocabgoAuto\materials。

自适应思考：

  • 基础词义、普通短语和填空题先关闭思考。
  • 答案为空、格式异常或多票冲突时，自动开启思考重试一次。
  • 句中专词义且没有本地证据时，直接使用思考模式。
  • 设置页可关闭“按题型自动切换思考模式”。

V2 已有修复：

  • 首次开始任务时可以重置选词。
  • 服务器返回 20001 后自动续答时不再发送 reset_chose_words。
  • 后续学习轮次不会反复回到 66%。
  • 测试任务、班级学习任务和自学任务使用独立轮数。

文件说明：

1. vocabgo-optimized-exe 已解压免安装 EXE，直接双击 Vocabgo.exe。

2. vocabgo-optimized-exe-win32.zip 免安装 EXE 压缩包，适合没有 Python 的同学。

3. vocabgo-optimized-source-auto-python.zip 源码包；没有 Python 时会自动下载并校验官方 Python。

首次使用：

1. 启动 EXE 或 启动.bat。 2. 在“设置”页填写自己的 DeepSeek API Key，可选。 3. 按需导入四级词表或教材。 4. 点击“登录获取令牌”，使用自己的微信扫码。 5. 刷新任务并选择开始刷题。

注意：

  • 每个人必须使用自己的微信令牌和 API Key。
  • 同一时间只能运行一个刷题器。
  • 题库、词典缓存和用户资料保存在 %LOCALAPPDATA%\VocabgoAuto。
  • 不要分享 config.json、bank.json、materials.json 或 API Key。

详细使用说明

词达人微信扫码自动答题工具

本项目基于 MIT 许可证开源项目 xuhaoranbb-boop/vocabgo-auto 的提交 3b766dfe76a7577d80ffd9ebab42a7eea7ba4e14，面向个人账号的志愿学习辅助使用。

首次使用

1. 双击 启动.bat。首次运行会自动创建 .venv 并安装依赖，需要保持联网。 2. 如果电脑没有安装 Python，启动脚本会自动从 python.org 下载并校验官方 Python 3.12，安装到项目内的 runtime 目录，不修改系统 Python。 3. 安装完成后会在项目内创建 .venv，以后启动不再重复下载。 4. 在「设置」页可选择填写 DeepSeek 接口密钥；不填写也能运行，但遇到题库未覆盖的题目时正确率会下降。 5. 可在「设置」页的「本地资料库」导入 TXT、CSV、JSON、DOCX、EPUB 或文字型 PDF 词表和教材。 6. 回到「刷题」页，点击「登录获取令牌」。 7. 选择微信扫码，按界面提示在微信中完成授权，再把带 code 的链接粘回程序。 8. 点击「刷新任务」可逐条选择任务；也可以直接点击「一键全部刷完」。

本地资料库

  • 脚本先在本地解析、去重和检索资料，上传和查询资料本身不消耗大模型 token。
  • 词表格式支持 ubiquitous adj. 普遍存在的；无处不在的、word=释义、CSV 和 JSON。
  • 中文短语格式支持 许多例子 = many examples。
  • 明确命中的选择题或短语题直接作答；无法确定时，只把当前题目和少量相关片段交给模型。
  • 扫描版 PDF 如果没有可提取文字，会提示先做 OCR；带密码或 DRM 的电子书无法读取。
  • 资料保存在 %LOCALAPPDATA%\VocabgoAuto\materials，不会写进分享包。

自适应思考

  • 默认开启“按题型自动切换思考模式”。
  • 基础词义、短语组词和普通填空先关闭思考，减少推理 token。
  • 答案为空、格式异常或多票冲突时，自动开启思考重试一次。
  • 句中专词义且没有本地词典或资料证据时，直接使用思考模式。
  • 关闭该选项后，模型会固定使用“思考模式”下拉框里的设置。

一键全部刷完

  • 自动处理所有进度未满、已经开始作答的班级任务，不再自动处理自学任务，也不再用自学任务给班级任务备题。
  • 一键全刷中，班级任务只按 progress < 100 加入；进度已经 100% 的任务不会因为得分较低而重复刷。自学任务则以任务得分 100 为完成线。
  • 班级任务开跑前会先用对应自学任务补题库，题库覆盖达到安全线后才作答。
  • 覆盖不足时会跳过该班级任务，避免浪费一次性作答机会；日志会说明跳过了几条。
  • 尚未开始的班级任务需要先在词达人微信端点开一次，再回来重新运行。
  • 单条任务失败不会中断整批，程序会继续处理后面的任务。

刷选中任务

  • 任务列表支持 Ctrl 多选和 Shift 连续选择。
  • 选择多条班级任务后，点击“刷选中任务”即可依次自动完成。
  • 列表会标记 task_type=1 对应的“学习任务”和 task_type=2 对应的“测试任务”。
  • 测试任务只有一次机会，固定执行一次并默认只处理进度未满的任务。
  • 学习任务使用“班级学习轮数”，可以按设置重复学习。
  • 学习任务需要重刷进度 100% 的任务时，先勾选“允许重刷已完成学习任务”。
  • 未勾选时，进度 100% 的任务无论得分多少都会跳过。

微信作答说明

  • 登录必须通过微信授权；工具不会要求词达人账号密码。
  • 授权成功后，不要在手机、平板或另一台电脑上重复登录词达人，否则令牌可能失效。
  • 词达人令牌通常约 6 小时失效，程序会提前提示重新授权。
  • 班级任务通常只有一次机会。默认策略会先关闭“故意答错再试答案”，避免永久拉低成绩。
  • 不填大模型密钥也能运行，主要依靠备题题库、本地资料、在线词典和规则匹配；若希望生词题正确率更高，建议在设置页配置 DeepSeek 密钥。
  • 班级任务默认会把难题独立询问大模型 3 次并取多数答案，正确率更高，但也会增加模型调用次数和耗时。
  • 短语组词题会严格校验空格数量和选项池；模型推理额度用完或返回空内容时会自动放大额度重试，最多补采样到五票。
  • mode 51 无选项填空题会调用专用填空提示词，例如 plain {}（平民百姓） 会提交 folk，不再错误提交 0。
  • 其他只要没有选项、也不是短语排序的题型，同样会自动使用填空模型，不再因 mode 编号变化而提交 0。
  • mode 22 单词选义题会按旧答案的释义内容复用题库，即使选项顺序和标点变化也能命中；出现多个可能答案时交给大模型，绝不按旧下标硬选。
  • 班级任务遇到 20004 任务已完成 时会读取真实进度：低于 100% 自动重连续答，最多 5 次；达到 100% 才停止。
  • 遇到 20001 需要选词 时会自动重新读取未达标单词并继续，不再把“本轮选词结束”误认为整条任务完成。
  • 自动续答会对比服务器总进度；如果新会话完成后总进度没有提升，会停止重复循环并保留日志，避免反复从 1/79 开始。
  • 界面的“自学轮数”只作用于自学任务；班级任务固定使用任务内自动续答，不会被外层轮数重复整条执行。
  • 工具使用系统单实例锁，重复双击启动时会提示已有实例，避免两个窗口同时写题库。
  • 如果日志出现 HTTP 401 Authentication Fails，说明 API Key 无效，程序会停止重复请求并转入题库兜底；需要重新创建密钥。

隐私与风险

  • config.json 会保存微信授权令牌和可选的大模型密钥，不要上传或发送给他人。
  • 题库 bank.json、词典缓存和用户资料会自动保存在 %LOCALAPPDATA%\VocabgoAuto，不会留在桌面程序目录，避免 QQ 扫描、上传或同步文件时占用题库，也不会把个人教材打进分享包。
  • 自动化操作可能受平台规则和接口更新影响；请仅在自己的账号上低频使用，并遵守学校与平台要求。

本地资料与优化

优化版 V3 说明

本版本在原有题库、答题、批量任务和继续练习修复的基础上，新增两项主要能力。

本地资料库

  • 支持导入 TXT、MD、CSV、JSON、DOCX、EPUB 和文字型 PDF。
  • 自动识别词表、短语和教材正文。
  • 词表格式支持 ubiquitous adj. 普遍存在的、word=释义、CSV 和 JSON。
  • 短语格式支持 许多例子 = many examples。
  • 明确命中的题目由脚本直接作答，不调用大模型。
  • 无法确定时只发送相关片段，不上传整本电子书。
  • 资料保存在 %LOCALAPPDATA%\VocabgoAuto\materials。

扫描版 PDF 如果没有可提取文字，会提示先做 OCR；带密码或 DRM 的电子书无法读取。

自适应思考

  • 基础词义、普通短语和填空题先关闭思考。
  • 没有稳定答案、格式异常或多票冲突时，开启思考重试一次。
  • mode=11 句中专词义且没有本地证据时，直接使用思考模式。
  • 有词典或资料证据时，优先关闭思考。

真实测试使用 12 道已知答案题：

  • 关闭思考：输出 21 token，推理 0，总 token 1,064。
  • 开启思考：输出 579 token，推理 546，总 token 1,922。
  • 两种模式在该批基础题上的有效正确率相同。

这证明基础题默认关闭思考可以减少开销，但复杂题仍保留升级到思考模式的能力。

缓存说明

  • DeepSeek 的缓存是尽力而为，不保证 100% 命中。
  • 短提示可能无法形成稳定缓存。
  • 简单地在完整任务中反复携带历史会扩大总输入，命中率提高也可能更贵。
  • 本版本不保存整轮 100 题历史，改用本地题库和资料库减少模型调用。

缓存策略说明

缓存优化版说明

本版本保留原版全部答题逻辑，仅调整大模型请求的缓存布局：

  • 系统提示固定，不再包含每次变化的 UUID。
  • 采样编号移动到用户提示末尾。
  • 完整保留 3 次投票和短语补采样，不减少判断次数。
  • 记录缓存命中输入、未命中输入、推理输出和总 token。
  • 题目、选项、词典释义、模型、思考模式和答案解析均未改变。

DeepSeek 的上下文缓存由服务端自动管理。缓存写入需要数秒，并且短前缀可能不会形成可命中的缓存单元。较长且重复的公共前缀更容易命中。

实测参考：

  • 约 112 token 的短提示：缓存命中 0%。
  • 约 2200 token 的稳定前缀：第三次请求后命中率约 91.2%。

因此本优化不会改变答题效果，但缓存提升幅度取决于实际题目的提示长度和重复程度。

继续练习修复

继续练习重置修复

本次修复解决学习任务完成部分阶段后反复回到 66% 的问题。

  • 首次开始任务或主动重新选词时，仍可发送 reset_chose_words=1。
  • 服务器返回 20001 需要选词 后的自动续答不发送重置字段。
  • 同一任务后续答题会话不重复重置。
  • 班级学习任务会读取 exist_little_task：
  • 2：开始选词，首次允许重置。
  • 1：继续练习，通常不重置。
  • 如果服务器返回“存在小节任务未完成”，学习任务和测试任务都会自动带 reset_chose_words=1 重试一次。
  • 该重试只清除当前未完成的选词批次，不会清空已提交成绩。
  • 自学任务也采用相同规则。
  • CLI 与 GUI 均已同步。

题目、答案策略、轮数设置、配置、令牌和题库均未改变。
